# Catatan Saham · data publik

Hasil olahan Catatan Saham untuk aplikasi **Catatan Saham Non Admin**. Diisi otomatis oleh robot dari repo admin (privat).

| File | Isi |
|---|---|
| `data/versi.json` | tanggal data terakhir dan waktu terbit |
| `data/cleanbuy/terbaru.json`, `data/cleanbuy/<tanggal>.json` | daftar kode Clean Buy 1/2/3 per hari |
| `data/makro.json` | PDB, inflasi, BI-Rate per kuartal |
| `data/radar.json` | judul berita ganti pengendali / tender offer / backdoor |

Tidak berisi data mentah (broksum, file harian) maupun rumus.

Bukan rekomendasi, hanya catatan analisis.
